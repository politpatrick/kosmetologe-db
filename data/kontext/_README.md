# Projektkontext

Hier landen die Inhalte aus dem claude.ai-Projekt „Kosmetologe“: Projektanweisungen, Zielgruppe, Tonalität, Design-Vorgaben, Code-Konventionen.
Jede Datei ist ein Eintrag vom Typ `kontext` mit Feld `einsatz` (design | code | text | beratung | skill),
damit Claude bei Design-, Code- oder Textaufgaben gezielt den passenden Kontext lädt.

Vorlage: siehe `_vorlage.md`. Dateien mit `_` am Anfang werden vom Index ignoriert.
